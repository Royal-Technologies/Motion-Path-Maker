# Motion Path Maker

A lightweight browser-based **Motion Path Maker** for creating and experimenting with custom motion paths for web animations.

Built by **Royal Technologies**, this tool is designed for web designers and developers who want to visually create motion paths and use them in interactive websites and animation projects.

## About

**Motion Path Maker** is a browser-based visual tool for experimenting with motion paths.

Motion paths allow elements to follow a custom route instead of moving only horizontally or vertically. They are useful for creating interactive hero sections, animated interfaces, creative landing pages, presentations, and other web experiences.

The project is designed as a simple frontend application that can be used directly from a modern web browser.

## Motion Path in Web Animation

Motion paths can be used with modern web animation techniques to move an element along a custom route.

For example, CSS provides motion path properties such as:

```css
.element {
    offset-path: path("M 0 100 C 100 0, 200 200, 300 100");
    offset-distance: 50%;
}
```

The generated path can also be adapted for JavaScript animation libraries and SVG-based animations.

## Integration

Motion paths created with this type of workflow can be adapted for:

* CSS Motion Path
* SVG
* JavaScript
* GSAP
* Scroll-based animations
* Interactive UI components
* WordPress
* Elementor
* Custom web applications

Example:

```javascript
element.animate(
    [
        { offsetDistance: "0%" },
        { offsetDistance: "100%" }
    ],
    {
        duration: 3000,
        iterations: Infinity
    }
);
```
